# Planning & Working Notes (Internal)

This directory holds **internal planning and working documents** — product strategy, design analyses, and roadmap notes produced while building owlctl. They are **not user documentation**, are not maintained alongside the code, and may be outdated or describe deprecated or unbuilt features.

For user-facing documentation, see [`../docs/`](../docs/) — start with the [Getting Started Guide](../docs/getting-started.md).

## Contents

- `strategy.md` — Product strategy and "Terraform for Veeam" roadmap analysis
- `agent-governance-layer.md` — Forward-looking design vision (largely unbuilt)
- `security-drift-report.md` — Security drift coverage planning
- `analysis.md` — Original declarative-mode design brief
- `ado-features-needed.md` — Azure DevOps feature-gap notes (track live work in GitHub Issues)
- `demo-environment-setup.md` — Demo walkthrough (predates the `--instance` model; uses the deprecated `targets`/`--target` approach)

> Treat anything here as a snapshot of thinking at the time it was written, not as current guidance.
